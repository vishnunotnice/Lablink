# Next development milestones

1. Validate the reconstruction on a disposable Ubuntu hub and Linux/Windows nodes.
2. Import existing peers without replacing the working four-node overlay.
3. Add a routed zone provider so declared cross-zone flows work end to end.
4. Add a libvirt or Proxmox provider with real VM snapshot/reset hooks.
5. Add coordinated volume backup and application-consistent container recovery.
6. Add heartbeat metadata, handshake age, service probes and richer diagnostics.
7. Add a full-screen TUI, dry-run configuration differences and export bundles.
8. Add packaged releases, pinned container images and a chosen open-source license.

NetScope integration, REST administration, web dashboard, cloud support, AI and marketplace features remain outside the requested near-term scope. The enrollment HTTP interface is a narrow registration transport, not a REST administration API.
